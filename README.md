## 06 / DESIGN PRINCIPLES

I care about software that feels **considered**, not merely functional.

My visual direction is built around:

```text
TYPOGRAPHY
     +
SPACING
     +
HIERARCHY
     +
INTERACTION
     +
MOTION
     +
SYSTEMS
```

I prefer:

- intentional interfaces over generic templates
- restrained motion over constant animation
- useful 3D over decorative 3D
- strong typography over visual noise
- clear systems over one-off effects
- accessible UX without flattening the visual character
- technology that strengthens the experience rather than becoming the experience
